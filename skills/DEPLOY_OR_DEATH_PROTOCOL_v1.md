# 💀 DEPLOY OR DEATH PROTOCOL v1.0

È severamente vietato dichiarare un task concluso senza aver eseguito:
1. **Git Push**: Verifica che tutto il codice sia sincronizzato sul repository remoto.
2. **Verifica Deploy su Vercel**: Controlla che il build su Vercel sia andato a buon fine (o equivalenti).
3. **Consegna del link di produzione**: Fornisci all'utente il link aggiornato (es. https://rengatreffen.it/iscrizioni) per la verifica finale.

*Infrangere questo protocollo comporta il fallimento della missione.*
